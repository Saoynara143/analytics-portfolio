# Аналитика заказов маркетплейса на SQL

## Бизнес-задача

У небольшого FBS-продавца есть заказы, закупочные цены, комиссии и расходы. Нужно понять: сколько компания зарабатывает **после всех переменных затрат**, какие товары дают наибольший вклад, меняется ли прибыль по месяцам и приходят ли клиенты повторно.

**Данные:** 3 200 сгенерированных заказов за январь—июнь 2026 года, 36 синтетических SKU, ~700 покупателей. Все числа относятся к учебной модели. Реальных заказов и сведений о покупателях здесь нет.

**Формула для завершённого заказа**

`выручка = количество × цена`; `маржинальный доход = выручка − закупка × количество − комиссия − логистика − эквайринг − налог − реклама`.

Для отменённых и возвращённых заказов выручка не признаётся; их операционные затраты отдельно не входят в основную unit-экономику. Это **упрощённая модель**, не бухгалтерская чистая прибыль. Возвраты считаются отдельно.

## Запуск

Из корня репозитория:

```bash
python 01_marketplace_sql/run_sql.py
```

Скрипт загружает [`data/orders.csv`](data/orders.csv) во временную SQLite-базу, выполняет все SQL-файлы и сохраняет результат каждого в [`results/`](results/). База не требует установки. SQL использует SQL-конструкции, доступные и в PostgreSQL, и в современной SQLite (с оконными функциями).

## Аналитические оговорки

- Только заказы со статусом `delivered` формируют выручку и contribution profit.
- В реальной экономике FBS нужно также учесть хранение, персонал, фиксированные расходы, компенсации возвратов и правила признания налогов.
- Синтетические клиенты не являются реальными людьми; показатели retention — только демонстрация SQL.
