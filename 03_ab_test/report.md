## Интерпретация

На синтетических данных разница по основной метрике статистически значима при α=0.05. Это **не рекомендация выкатывать изменение в реальный продукт**: отсутствуют заранее заданный размер выборки, подтверждённая длительность, проверка guardrail-метрик и реальный экспериментальный контекст.

## Методология

ITT: в знаменатель включены все рандомизированные пользователи, без фильтрации по тем, кто начал регистрацию. Для основной метрики — pooled z-test для p-value, нормальный unpooled ДИ разницы; для SRM — проверка отклонения от ожидаемого 50/50.
